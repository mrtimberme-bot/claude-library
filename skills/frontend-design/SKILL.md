# Frontend Design Skill

Ontwerpt en bouwt productie-klare UI in HTML, CSS, JS en React met focus op visuele kwaliteit en merkidentiteit. Vermijdt generieke AI-esthetiek via custom design tokens, microinteracties en doordachte typografie.

Niet voor code-review of accessibility-auditing — gebruik daarvoor de gespecialiseerde skills.

## Wanneer te gebruiken

Trigger bij: "bouw een dashboard", "maak een React component", "ontwerp een landingspagina", "maak een UI voor...".

## Aanpak

1. Kies een bewuste esthetische richting: minimalistisch, brutalist, editorial, etc.
2. Definieer design tokens (kleur, typografie, spacing) voor het component
3. Bouw mobile-first met progressieve enhancement
4. Voeg microinteracties toe voor feedback en levendigheid

## Beperkingen

- Geen accessibility-audit — gebruik HIG Compliance of Accessibility Auditor
- Geen backend/API integratie tenzij expliciet gevraagd
