# CLAUDE.md Memory

Sla gebruikersvoorkeuren, werkwijze en projectcontext op in CLAUDE.md zodat elke sessie direct in de juiste context start.

## Gebruik

Maak of bewerk `/project-root/CLAUDE.md` met:
- Naam en stijlvoorkeuren
- Actieve skills en plugins
- Projectcontext en architectuur
- Werkwijze-afspraken

Claude leest dit bestand automatisch bij elke sessie.
