Handleiding

      
Start iOS project

      
Van nul naar een volledig geconfigureerd iOS project met de golden skillset — in één commando.

    


    


      
      

        
01

        

          
Installeer de golden skillset globaal

          
Installeer alle 46 iOS skills naar ~/.claude/skills/ zodat Claude ze in elke sessie beschikbaar heeft.

          
python3 ~/Claude/Library/library-fetch.py --set ios-golden

          
Dit installeert alle skills uit de ios-golden set: setup, architecture, UI, testing, CI/CD en App Store — de complete iOS lifecycle.

        

      


      
      

        
02

        

          
Maak een nieuw Xcode-project aan

          
Maak een projectmap aan, initialiseer git, en stel Tuist in.

          
mkdir -p ~/Projects/MijnApp && cd ~/Projects/MijnApp
git init
tuist init --name MijnApp --platform iOS

        

      


      
      

        
03

        

          
Maak een lokale skill-snapshot in het project

          
Kopieer de golden skills naar .claude/skills/ in het project. Dit is een momentopname die meegaat in git — ook als de library later groeit blijft je project reproduceerbaar.

          
mkdir -p .claude/skills
python3 ~/Claude/Library/library-fetch.py --set ios-golden --output .claude/skills/

        

      


      
      

        
04

        

          
Schrijf CLAUDE.md met skill-index

          
Maak een CLAUDE.md in de projectroot. Claude leest dit bij elke sessie en weet direct welke skills beschikbaar zijn en voor welke fase.

          
# MijnApp — CLAUDE.md

## Skills (ios-golden)

### Fase 1 · Setup & architectuur
ios-baseline, ios-blok-workflow, swift-architecture, tuist-expert, swift-api-design-guidelines

### Fase 2 · Development
swift-concurrency-expert, swift-reviewer, swift-formatstyle, swiftdata-expert, core-data-expert, swiftdata-cloudkit

### Fase 3 · Testing & debugging
swift-testing-expert, ios-testing, debug-detective, instruments-profiling, swiftui-performance-audit

### Fase 4 · UI / Design
hig-compliance, swiftui-design-principles, swiftui-liquid-glass, figma-to-swiftui
ui-design-craft, theme-designer, motion-designer, haptics-designer, ux-designer, onboarding-designer
apple-accessibility-enhanced, focus-engine-tvos

### Fase 5 · Features
push-notifications-expert, widgetkit-liveactivities, app-intents-expert, apple-foundation-models, storekit-iap, localization-manager

### Fase 6 · Privacy & security
privacy-manifest, security-auditor

### Fase 7 · Build & CI/CD
xcode-simulator-expert, ios-build-verify, ios-cicd

### Fase 8 · App Store
app-store-readiness, app-store-review-compliance, app-store-connect-automation

### Fase 9 · Post-launch
post-launch

## Skills updaten
python3 ~/Claude/Library/library-fetch.py --set ios-golden --output .claude/skills/

        

      


      
      

        
05

        

          
Voeg een startup-hook toe

          
De hook controleert bij elke nieuwe sessie automatisch of er skill-updates beschikbaar zijn. Maak .claude/settings.json aan:

          
{
  "hooks": {
    "UserPromptSubmit": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "python3 ~/Claude/Library/library-fetch.py --check-updates ios-golden 2>/dev/null || true"
          }
        ]
      }
    ]
  }
}

          
Claude ontvangt de hook-output als context en meldt updates aan jou. Typ dan ja om bij te werken.

        

      


      
      

        
06

        

          
Voeg /check-skills toe als slash command

          
Maak .claude/commands/check-skills.md aan voor een handmatige update-check op elk moment:

          
mkdir -p .claude/commands
# Maak .claude/commands/check-skills.md aan met:
# Voer uit: python3 ~/Claude/Library/library-fetch.py --check-updates ios-golden
# Toon welke skills up-to-date zijn en welke updates hebben.
# Vraag of ik wil bijwerken.

          
Gebruik met /check-skills in elke Claude Code sessie in dit project.

        

      


      
      

        
07

        

          
Eerste commit

          
Commit alles inclusief de skill-snapshot.

          
git add -A
git commit -m "chore: init project met ios-golden skillset"
